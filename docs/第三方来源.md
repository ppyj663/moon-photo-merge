# 第三方来源和许可证

本项目代码按根目录的 Apache-2.0 许可证发布。项目通过 MoonBit 包管理器获取下列依赖，仓库没有复制这些依赖的源码。表中的许可信息来自本次解析到的各依赖 `moon.mod`；重新发布包含依赖的二进制时，应同时检查并保留各依赖随附的许可证和版权声明。

| 依赖 | 本次解析版本 | 模块声明 | 来源 |
| --- | --- | --- | --- |
| gmlewis/image | 0.17.18 | Apache-2.0 | [moonbit-image](https://github.com/gmlewis/moonbit-image) |
| gmlewis/io | 0.23.20 | Apache-2.0 | [moonbit-io](https://github.com/gmlewis/moonbit-io) |
| gmlewis/flate | 0.36.17 | Apache-2.0 | [moonbit-flate](https://github.com/gmlewis/moonbit-flate) |
| gmlewis/hash | 0.21.2 | Apache-2.0 | [moonbit-hash](https://github.com/gmlewis/moonbit-hash) |
| gmlewis/zlib | 0.21.17 | Apache-2.0 | [moonbit-zlib](https://github.com/gmlewis/moonbit-zlib) |
| gmlewis/base64 | 0.16.14 | Apache-2.0 | [moonbit-base64](https://github.com/gmlewis/moonbit-base64) |

`image` 和 `io` 为直接依赖，其余为传递依赖。上游部分 PNG 和 DEFLATE 源码注明参考 Go 实现及 Go Authors 的版权；Go 的 [BSD 风格许可证](https://go.googlesource.com/go/+/refs/tags/go1.23.3/LICENSE)应与上游文件声明一并核查。`gmlewis/flate` 的部分子目录还附带独立的 MIT 许可证。以上模块级声明不替代对上游各文件许可的检查。

真实照片基准使用 scikit-image 的公开样本，来源和复现方法见[基准说明](../benchmarks/README.md)。项目中其余演示图像为合成夹具。项目使用 Codex 辅助编写；项目目标、判断规则、数据处理边界和测试可通过 README 与代码复现。
