# MoonBit photo merge expansion plan

## Goal

Grow the maintained MoonBit implementation to about 3,000 meaningful lines, including tests, while keeping the photo merge workflow understandable and safe. New code must deliver observable user capabilities; no generated files, dead utilities, or line-count padding.

## Architecture

- Keep the command-line adapter responsible for filesystem access and the MoonBit library responsible for deterministic domain decisions.
- Extend the photo model with image metadata and scan diagnostics.
- Split visual matching into explainable fingerprint components, candidate ranking, and duplicate-group analysis.
- Add deterministic import planning, collision-safe destination naming, image inventory summaries, and machine-readable exports with focused pure functions.
- Preserve the existing rule that the tool only recommends similarity; it never removes or overwrites source files.
- Keep browser rendering and filesystem operations in the existing JS adapter, with validated boundaries and integration coverage.

## Implementation stages

1. **Domain models and input policy** — complete: add image metadata, path/name normalization, size/dimension summaries, and query filtering with boundary tests.
2. **Similarity analysis** — complete: add segmented candidate indexing, exact distance verification, stable ranking, and transitive group summaries.
3. **Photo groups and review summaries** — complete: identify exact/similar groups, category counts, size totals, and review workload summaries.
4. **Import and report workflow** — complete: preserve deterministic decisions and no-overwrite copy checks; export review, inventory, extension, and similarity-group data in CSV/JSON.
5. **Review experience and integration** — complete: show image evidence and summaries in the local report; test scans, approvals, export escaping, and safe copy.
6. **Finish and measure** — complete: format, refresh interfaces, run project checks, and measure maintained `.mbt` files.

## Acceptance checks

- `moon fmt`, `moon info`, `moon check --target js`, `moon test --target js`, `moon build --target js`, `node scripts/integration-test.mjs`, and `node scripts/demo.mjs` pass.
- Tests cover deterministic ranking/grouping, path safety, metadata/statistics boundaries, escaped exports, stale approvals, and safe copy behavior.
- Maintained `.mbt` source and test files exceed 3,000 lines; generated and dependency files are excluded from the count.
- User-facing docs describe the added capabilities and limits without promising unsupported recognition accuracy.
