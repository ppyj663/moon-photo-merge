## 本机复现

```powershell
moon update
moon info
moon fmt
moon check --target js
moon build --target js
moon test --target js
node scripts/integration-test.mjs
node scripts/demo.mjs
node scripts/benchmark.mjs examples/fixtures/library examples/fixtures/incoming --runs 2
```

演示仅操作临时副本。需要验收真实照片目录时，可将自己的现有相册和备份目录传给 `scripts/benchmark.mjs`；基准摘要不包含文件路径、名称、哈希或图像内容。仓库中的基准记录使用合成夹具，不能代表真实个人相册的性能或识别准确率。

## 验收边界

项目覆盖本地 JPEG/PNG 的重复筛查、疑似相似提示、同名冲突复核和用户确认后的安全复制；不承诺识别所有近似照片，不处理 HEIC、RAW、视频或云端相册。最终验收仍以赛事组织方的实际审核结果为准。
